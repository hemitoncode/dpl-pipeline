Coded results will appear here, one card per bill.
Deterministic by construction: the same bill text and the same rule lexicon always produce the same coding. Every record carries the rule IDs and text excerpts that triggered it, plus a SHA-256 of the classified text, so results are auditable and reproducible. Records flagged needs review — and any policy-significant coding — should be confirmed by a human coder; the lexicon is a screening instrument, not a final judgment.
